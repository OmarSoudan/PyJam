## 1. Introduction to PyJam

PyJam is a programmatic environment for audio synthesis, signal processing, and musical arrangement. Unlike traditional MIDI-based libraries, PyJam synthesizes audio at the sample level, allowing for real-time manipulation of waveforms via a virtual "Pedalboard" architecture.

### 1.1 Core Philosophy

PyJam operates on three primary abstractions:

1. **Instruments (Oscillators/Synthesizers):** Generate raw waveforms.
2. **Effects (Processors):** Modify waveforms using digital signal processing (DSP).
3. **Engine (The Host):** Manages frequencies, sample rates, and file serialization.

---

## 2. The Audio Engine (`pyjam.engine`)

The `AudioEngine` is the foundation of the library. It handles the mathematical translation of music theory into physics.

### 2.1 Frequency Mapping

PyJam uses **Scientific Pitch Notation (SPN)**. The engine maps string-based notes (e.g., "A4") to their corresponding frequencies in Hertz.

| Note | Frequency (Octave 4) |
| --- | --- |
| C | 261.63 Hz |
| A | 440.00 Hz |
| B | 493.88 Hz |

### 2.2 Key Methods

* `get_freq(note_str)`: Parses a note name and octave. If the octave is omitted, it defaults to 4.
* `normalize(signal, volume)`: Prevents digital clipping by scaling the peak amplitude to a specified float (default 0.8).
* `save(signal, filename)`: Writes the final array to high-quality 16-bit WAV and compressed MP3 formats.

---

## 3. The Instrument Architecture (`pyjam.instruments`)

Every instrument inherits from the base `Instrument` class, providing a unified API for chords, melodies, and arpeggios.

### 3.1 Base Methods

#### `play(note_str, duration)`

Generates a single note.

```python
piano = Piano()
audio = piano.play("C#5", 1.5)

```

#### `play_chord(chord_str, duration)`

Synthesizes multiple frequencies simultaneously and averages them to prevent distortion.

```python
guitar = ElectricGuitar()
audio = guitar.play_chord("Am7", 2.0)

```

#### `arpeggiate(chord_str, duration, pattern)`

Sequences chord notes over time.

```python
# Plays Root, Third, Fifth, Third
audio = guitar.arpeggiate("Cmaj", 2.0, pattern=[0, 1, 2, 1])

```

## 4. Instrument Catalog

PyJam includes specialized synthesis algorithms for different timbres.

### 4.1 Physical Modeling

* **AcousticGuitar:** Uses the **Karplus-Strong** algorithm. It initializes a buffer with white noise and passes it through a filtered delay line to simulate a plucked string.
* **Flute:** Combines a triangle wave with turbulent white noise to simulate breath through an embouchure.

### 4.2 Additive & FM Synthesis

* **Organ:** Sums multiple sine waves at harmonic intervals (fundamental, 2nd, 3rd) to simulate drawbars.
* **Bell:** Uses **FM (Frequency Modulation)** with inharmonic ratios (non-integer multipliers) to create metallic dissonance.
* **Strings:** Uses three detuned sawtooth waves to simulate the "chorus effect" of a string section.

### 4.3 Brass & Reeds

* **Trumpet:** Uses a rich harmonic spectrum with a bright "lip-tension" envelope.
* **Saxophone:** Employs asymmetric sawtooth waves passed through a `tanh` distortion to mimic reed vibration.

---

## 5. Virtual Pedalboard (`pyjam.effects`)

Effects are applied sequentially. Each effect takes a signal, modifies it, and returns it for the next "pedal" in the chain.

### 5.1 Dynamic Processing

* **Distortion:** Uses soft-clipping (`np.tanh`) to add grit and harmonics.
* **Wah:** A resonant state-variable filter that sweeps a bandpass peak across the frequency spectrum.

### 5.2 Time-Based Effects

* **Delay:** A feedback loop that adds a copy of the signal at a specified time interval.
* **Chorus:** Modulates the delay time with a low-frequency oscillator (LFO) to create thickness.
* **Tremolo:** Modulates the amplitude (volume) for a rhythmic "shimmer."

## 7. Advanced Usage & Examples

### 7.1 Creating a Cinematic Pad

To create a spacey, ambient sound, we combine `SynthPad` with high-feedback `Delay` and `Chorus`.

```python
from pyjam import SynthPad, Delay, Chorus, AudioEngine

pad = SynthPad(volume=0.3)
pad.add_effect(Chorus(rate=1.0, depth=0.005))
pad.add_effect(Delay(time=0.5, feedback=0.6))

audio = pad.play_chord("Fmaj7", 4.0)
AudioEngine.save(audio, "ambient_pad")

```

### 7.2 Writing a Melody Line

Because PyJam handles SPN, you can write melodies as simple lists.

```python
melody = [("C4", 0.5), ("E4", 0.5), ("G4", 0.5), ("C5", 1.0)]
piano = Piano()
track = []

for note, dur in melody:
    track.append(piano.play(note, dur))

final = np.concatenate(track)

```

## 8. Development: Adding New Instruments

Developers can extend PyJam by overriding the `play_raw` method.

### 8.1 Custom Sine Synth Example

```python
from pyjam.instruments import Instrument
import numpy as np

class PureSine(Instrument):
    def play_raw(self, freq, duration):
        t = np.linspace(0, duration, int(44100 * duration), False)
        return np.sin(2 * np.pi * freq * t)

```

## 9. Error Handling and Debugging

PyJam provides specific feedback for common errors:

1. **ValueError (Invalid Note):** Occurs if the pitch name is misspelled (e.g., "H4").
2. **ImportError (Bass/Wah):** Ensure `__init__.py` is updated when adding new modules.
3. **FFmpeg Error:** Occurs during `save()` if the system path does not include the FFmpeg binary.

---

## 10. Glossary of Terms

* **Clipping:** Digital distortion caused by audio levels exceeding 0dB.
* **Detuning:** Intentionally shifting a frequency slightly to create a thicker sound.
* **LFO:** A Low-Frequency Oscillator used to modulate other parameters (Tremolo/Wah).
* **PCM:** Pulse Code Modulation, the raw format used in WAV files.
